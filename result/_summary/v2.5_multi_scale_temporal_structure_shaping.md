# v2.5 理论总结：Multi-scale Temporal Structure Shaping

## 1. 核心问题

我们的目标不是寻找某一组固定结构权重，而是回答一个更本质的问题：

> 为什么只约束源域时序结构，就可能提升后续域适应效果？
> 为什么不同任务需要不同的结构约束位置、粒度和力度？

在 v2.4.3b 中，我们在 PSE 与 LTAE 之间加入轻量级 temporal reshaper，并只在源域上施加结构约束。实验表明，这可以提升多个遥感 source-target 任务的 TimeMatch 表现。

但后续实验也说明：不存在一个对所有任务都稳定最优的固定 view。不同任务可能偏好：

- global / noseg compactness；
- uniform segmented compactness；
- DOY-gap segmented compactness；
- trajectory dynamics；
- 不同强度的 compactness；
- 是否启用 dual-path semantic preservation。

因此，v2.5 不应被理解为“寻找最佳分段方式”，而应被定义为：

> Multi-scale Temporal Structure Shaping：通过不同时间尺度和不同结构刚性的 source-side structure view，重塑源域时序特征，使其更适合后续目标域对齐。

---

## 2. TimeMatch 与 Reshaper 的关系

原始 TimeMatch 的核心不是直接移动 PSE 输出特征值，而是通过时间位置偏移改变 LTAE 对特征序列的时间解释：

```text
pixels
  -> PSE
  -> F_raw(t)
  -> LTAE(F_raw, position + shift)
  -> classifier
```

也就是说，TimeMatch 对齐的主要是 temporal position / positional encoding：

```text
position_target + target_to_source_shift
position_source + source_to_target_shift
```

我们的 reshaper 插入在 PSE 与 LTAE 之间：

```text
raw pixel-set sequence
  -> PSE
  -> F_raw
  -> temporal reshaper
  -> F_reshaped
  -> LTAE
  -> classifier / TimeMatch DA
```

令源域样本的 PSE 输出为：

$$
F_i = [f_i(1), f_i(2), \ldots, f_i(T)], \quad f_i(t) \in \mathbb{R}^{d}
$$

reshaper 采用残差形式：

$$
\tilde{F}_i = F_i + \alpha R_\theta(F_i)
$$

其中：

- \(F_i\)：原始 PSE 时序特征；
- \(R_\theta(\cdot)\)：temporal residual conv reshaper；
- \(\alpha\)：reshaper strength；
- \(\tilde{F}_i\)：reshaped source feature。

结构损失主要约束 \(\tilde{F}_i\)，而不是直接强行改变 PSE 本体。这一点很重要：我们希望 reshaper 整理源域结构，同时尽量避免破坏目标域共享编码空间。

---

## 3. 统一观点：结构约束改变的是对齐几何

域适应最终不是让源域本身越紧越好，而是让目标域样本经过对齐后，能够落入正确的源域类别结构附近。

设类别 \(c\) 的源域结构原型为：

$$
P_c(t)
$$

目标域样本经过编码和对齐后为：

$$
A(F^{tgt})(t)
$$

其中 \(A(\cdot)\) 表示 TimeMatch 这类时间对齐机制。理想情况下：

$$
d(A(F^{tgt}), P_y) < d(A(F^{tgt}), P_k), \quad k \neq y
$$

结构约束影响的是：

1. 源域类别原型 \(P_c\) 的形状；
2. 同类样本围绕原型的紧致程度；
3. 不同类别结构之间的间隔；
4. 目标域在存在残余错位时的对齐容错性。

因此，结构约束的作用不是简单“提高源域分类性能”，而是塑造一种更适合 DA 的源域特征几何。

可以用一个风险分解直观理解：

$$
R_{UDA}
\approx
R_{src}^{cls}
+ R_{align}
+ R_{stiff}
$$

其中：

- \(R_{src}^{cls}\)：源域判别风险；
- \(R_{align}\)：目标域对齐误差；
- \(R_{stiff}\)：源域结构过度刚性导致的对齐容错下降。

适度结构约束可以降低 \(R_{src}^{cls}\) 和部分 \(R_{align}\)，但过强、过细、位置不合适的约束会增加 \(R_{stiff}\)。这解释了为什么结构权重并非越大越好，分段也并非越细越好。

## 4. Temporal Structure View

我们将“分段”推广为 temporal structure view。

给定时间划分：

$$
\mathcal{S} = \{S_1, S_2, \ldots, S_K\}
$$

其中每个 \(S_k\) 是一组时间点。不同 \(K\)、不同构造方式、不同距离定义，对应不同 structure view。

| view | 含义 | 适用假设 |
| --- | --- | --- |
| global / noseg | \(K=1\)，整条曲线作为一个结构单元 | 类别结构主要体现在整体轨迹，或局部分段不可靠 |
| uniform segmented | 按时间索引均匀划分 | 类别判别或域偏移具有局部性，但观测间隔语义不强 |
| DOY-gap segmented | 按观测日期间隔划分 | 不均匀采样、缺测或大时间空洞会影响结构连续性 |
| trajectory dynamics | 约束局部变化方向 | 时间位置不稳定，但变化模式相对稳定 |
| dual-path relation | 保持 raw/reshaped 语义关系 | 防止 reshaper 破坏原有类别语义，不是结构 view 本身 |

分段的意义不是寻找绝对真实的物候阶段，而是为结构约束提供局部观察窗口。

---

## 5. 结构约束的统一形式

整体结构损失可以写成：

$$
\mathcal{L}_{structure}
=
\sum_{m \in \mathcal{V}}
\lambda_m D_m(\tilde{F}_i, P_c)
$$

其中：

- \(\mathcal{V}\)：结构视图集合；
- \(D_m\)：某一 view 下的结构距离；
- \(\lambda_m\)：该结构 view 的约束力度。

这说明 v2.5 的自适应有两个核心 knob：

1. **scale / view**：约束哪个尺度、哪个位置的结构；
2. **stiffness / strength**：约束多强。

### 5.1 Global Compactness

global compactness 将整条轨迹作为一个结构单元：

$$
\mathcal{L}_{intra}^{global}
=
\sum_c \sum_{i \in \mathcal{I}_c}
\left\|
\phi(\tilde{F}_i) - \phi(P_c)
\right\|_2^2
$$

其中 \(\phi(\cdot)\) 是整条轨迹的池化表示。

它的优点是低风险、稳定，不会强行要求每个局部阶段严格对应。缺点是可能平均掉局部判别结构。

### 5.2 Segmented Compactness

segmented compactness 在每个 segment 内分别构建局部原型：

$$
\mathcal{L}_{intra}^{seg}
=
\sum_c \sum_{i \in \mathcal{I}_c}
\sum_{k=1}^{K}
\left\|
\phi_{S_k}(\tilde{F}_i) - \phi_{S_k}(P_c)
\right\|_2^2
$$

它的意义是：让同类样本在局部时间窗口内形成更清晰的结构。

但如果 segment 位置错误，或者局部结构主要是 domain-specific variation，那么 segmented compactness 会把错误差异也压紧，导致 DA 阶段更难对齐。

### 5.3 Trajectory Dynamics

trajectory dynamics 不要求曲线更平滑，而是约束同类样本与类别 prototype 的局部变化方向一致：

$$
\Delta \tilde{F}_i(t) = \tilde{f}_i(t+1) - \tilde{f}_i(t)
$$

$$
\Delta P_c(t) = P_c(t+1) - P_c(t)
$$

$$
\mathcal{L}_{dyn}
=
\sum_c \sum_{i \in \mathcal{I}_c}
\sum_t
d(\Delta \tilde{F}_i(t), \Delta P_c(t))
$$

这个设计比旧 trend loss 更合理，因为它不假设高维 feature 曲线应该单调或平滑，而是假设同类样本的局部变化模式应与类别 prototype 一致。

当前实验显示 dynamics 在部分 HAR/HHAR 任务上很有价值，但在遥感任务中还不够稳定。因此它适合作为 multi-view bank 的重要成员，而不是单独主线。

### 5.4 Dual-path Relation

dual-path relation 的作用不是定义 temporal structure，而是 semantic preservation。

设 raw path 和 reshaped path 的样本关系分别为：

$$
G_{raw}(i,j)=sim(F_i,F_j)
$$

$$
G_{reshaped}(i,j)=sim(\tilde{F}_i,\tilde{F}_j)
$$

则：

$$
\mathcal{L}_{dual}
=
\|G_{raw}-G_{reshaped}\|^2
$$

它的定位是：

> reshaper 可以重塑结构，但不应该大幅改变样本之间的语义关系。

因此 dual-path 是保护项，不是结构成分本身。

## 6. 为什么约束位置和力度会影响 DA？

不同时间区域可能对应不同类型的信息。

### 6.1 Domain-invariant discriminative region

如果某个时间区域同时满足：

1. 类别判别性强；
2. 跨域差异相对可对齐；
3. 不主要由域特异噪声驱动；

那么在该位置施加结构约束有利于 DA。

### 6.2 Domain-specific variation region

如果某个时间区域主要反映源域特有采样、传感器响应或区域差异，那么强行 compact 会把 domain-specific pattern 固化到源域结构中，目标域更难对齐。

### 6.3 Alignment-sensitive region

如果某个区域类别判别性强，但 source-target 存在显著时间错位，那么过强的局部 compactness 会降低容错性。这时 dynamics、global 或更轻量的 compactness 可能更合适。

因此，结构约束真正要寻找的是：

> domain-invariant discriminative temporal structure。

这解释了为什么约束位置、粒度和力度都会影响域适应。

## 7. 遥感实验：View Taxonomy 的初步验证

### 7.1 代表性任务

我们在三个遥感任务上验证 structure view：

| 任务 | 选择原因 |
| --- | --- |
| `FR1 -> FR2` | 同国区域迁移，baseline 较强，检验是否需要分段 |
| `FR2 -> FR1` | 与 FR1->FR2 方向相反，检验方向性 |
| `DK1 -> FR1` | 跨国迁移，观测节奏和时序结构差异更强 |

### 7.2 结果

| 任务 | baseline | 旧 v2.4.3b best | v2.5 best | v2.5 best view | 诊断 best view | 结论 |
| --- | ---: | ---: | ---: | --- | --- | --- |
| `FR1 -> FR2` | 0.7946 | 0.8101 | 0.8086 | `uniform_k10_full` | `uniform:10` | fine-grained uniform view 有诊断依据，但 global strong compactness 仍非常强 |
| `FR2 -> FR1` | 0.6513 | 0.7580 | 0.7684 | `uniform_k5_full` | `uniform:10` | 需要局部分段；实验最优 K=5，说明不是越细越好 |
| `DK1 -> FR1` | 0.5683 | 0.6284 | 0.6218 | `doy_k5_no_dual` | `doy_gap:5` | DOY-gap view 与跨国不均匀观测差异更匹配 |

这些结果支持三个判断：

1. 分段有价值，但不是所有任务都需要分段；
2. 诊断可以解释 view 偏好，但不能直接等同于最优 K；
3. DOY-gap 的合理性来自 irregular sampling，而不是声称找到了真实物候阶段。

## 8. HAR/HHAR 通用时序验证

为了验证结构约束不是遥感特例，我们在 HAR / HHAR 上进行 multi-view 验证。

设置：

- 数据集：HAR、HHAR_SA；
- 任务数：10 个 source-target 任务；
- seeds：1, 2, 3；
- structure views：`compact_k5`, `compact_k3`, `compact_k8`, `intra_light_k5`, `noseg_global`, `dynamics_cosine`, `dynamics_mse`；
- 每个任务比较原版 TimeMatch baseline 与 source-side structure reshaper + TimeMatch。

### 8.1 总体结果

| 数据集 | source gains | source delta | DA gains | DA delta |
| --- | ---: | ---: | ---: | ---: |
| HAR | 11/15 | +0.0450 | 9/15 | +0.0239 |
| HHAR_SA | 13/15 | +0.0425 | 12/15 | +0.0488 |
| ALL | 24/30 | +0.0437 | 21/30 | +0.0364 |

这说明 source-side structure shaping 在非遥感时序上也有明显正信号。

### 8.2 固定 view 与 multi-view 的差异

固定 `compact_k5` 三 seed 的 DA 平均为负，而 multi-view bank 达到：

$$
21/30 \text{ positive runs}, \quad \Delta F1 = +0.0364
$$

这说明：

> 问题不在于结构约束无效，而在于单一固定 view 不能覆盖不同任务的结构需求。

### 8.3 View Preference

source 阶段最常赢：

| view | 次数 |
| --- | ---: |
| compact_k3 | 12 |
| compact_k5 | 7 |
| dynamics_mse | 4 |
| intra_light_k5 | 3 |
| compact_k8 | 2 |
| dynamics_cosine | 2 |

DA 阶段最常赢：

| view | 次数 |
| --- | ---: |
| compact_k5 | 7 |
| dynamics_mse | 6 |
| compact_k8 | 4 |
| dynamics_cosine | 4 |
| compact_k3 | 3 |
| intra_light_k5 | 3 |
| noseg_global | 3 |

这说明 source-only 最优的结构几何不一定是 DA 最优结构几何。更准确地说：

> source 训练更容易从局部 compactness 中获益；DA 阶段则更关注目标域对齐后的结构容错性，因此 dynamics/global/light views 开始变重要。

这不是要求 source 和 DA 一定使用两套 loss，而是说明 source-side shaping 的目标应从“最大化源域判别性”转向“形成 alignment-robust source structure”。

## 9. 当前结论

v2.5 的核心结论是：

> Source-side temporal structure shaping 是有效的，但有效结构不是唯一固定形式；它依赖 source-target temporal mismatch 的尺度、局部性、观测节奏和对齐容错需求。

因此，我们的方法不应表述为“提出一种固定分段策略”，而应表述为：

> 提出一个 multi-scale temporal structure shaping framework，在源域训练阶段通过不同 temporal structure views 约束 reshaper，使源域特征形成更清晰且更易对齐的类别时间结构。

| 模块 | 当前定位 |
| --- | --- |
| reshaper | 核心模块，负责重塑 PSE 后的源域时序特征 |
| compactness | 当前最稳定的结构目标 |
| segmentation | temporal view 的粒度和位置选择 |
| DOY-gap | irregular-sampling-aware temporal view |
| dynamics | alignment-robust structure view，HAR/HHAR 上有明显信号 |
| dual-path relation | semantic preservation，不是 temporal structure view 本身 |
| diagnostic script | 解释 view 偏好的工具，暂不作为自动 selector |

## 10. 下一步：从 View Bank 到 Adaptivity

当前结果已经说明：

1. 结构约束有效；
2. 固定 view 不够；
3. 不同任务偏好不同 structure view；
4. 不同 view 的约束力度也会影响 DA。

因此下一步自适应不应泛泛地说“调权重”，而应明确为两个问题：

### 10.1 Scale / View Adaptation

回答：

> 当前任务应该约束 global、local segment，还是 dynamics？

候选依据：

- source-target temporal mismatch 是否具有局部性；
- mismatch 是否与观测 gap 对齐；
- target pseudo features 到 source prototype 的距离分布；
- 不同 view 下的 target assignment margin。

### 10.2 Stiffness / Strength Adaptation

回答：

> 当前结构应压多紧？

候选依据：

- source class compactness；
- target-to-source prototype margin；
- alignment confidence；
- target pseudo-label entropy；
- source-target prototype distance；
- view 下的结构可靠性。

这对应一个更稳的自适应目标：

$$
\lambda_m = g(q_m)
$$

其中 \(q_m\) 是 view \(m\) 的结构可靠性或对齐可靠性。

---

## 11. 不应过度声称的内容

当前结果还不能支持以下结论：

1. 不能说某一个固定 view 或固定参数通用最优；
2. 不能说 DOY-gap 就是真实物候阶段；
3. 不能说 dynamics 已经完全替代 compactness；
4. 不能说已经完成自动自适应；
5. 不能说方法已在所有通用时序任务上普适，仅能说在遥感、HAR、HHAR 上有跨数据集正信号。

---

## 12. 推荐命名

原名“段划分理论一统”已经不够准确，因为当前理论核心不再只是 segmentation，而是：

- temporal structure view；
- multi-scale structure shaping；
- alignment robustness；
- adaptive view / stiffness。

推荐名称：

1. **v2.5 Multi-scale Temporal Structure Shaping 理论总结**
2. **源域时序结构塑形理论总结**
3. **Temporal Structure View 与源域结构塑形**
4. **Alignment-robust Temporal Structure Shaping**

其中最推荐：

> **v2.5 Multi-scale Temporal Structure Shaping 理论总结**

这个名字既保留 v2.5 阶段性，又不会把理论限制在“分段”。
